# 🛡️ Luyện Gõ · Game Học Từ Vựng & Boss Collocations B1–C2

Game bắn từ vựng tiếng Anh phong cách không gian với **1.008 từ vựng đơn + 500 Boss Collocations chuẩn CEFR B1–C2** chia thành **20 mốc chủ đề**. Ngay khi bắn hạ mỗi từ hoặc cụm từ, **nghĩa tiếng Việt, từ loại / cấu trúc và phiên âm IPA** sẽ xuất hiện kèm phát âm tiếng Anh.

🔗 **Chơi trực tuyến:** https://hoangductai1122-ship-it.github.io/vocab-shooter-b1-c2/

## Tính năng nổi bật
- **1.008 từ vựng đơn B1–C2** + **500 Boss Collocations** (25 cụm/chủ đề) trải đều 20 mốc.
- **Đấu Boss Collocation cuối mỗi màn:** 3 đợt Boss Collocation tăng dần độ khó (có thanh máu Boss, dấu cách `␣` trực quan, gõ sai Boss sẽ lao xuống gần hơn!), cộng thêm chế độ **👑 Chỉ săn Boss Collocations**.
- **Chọn vũ khí & loại đạn tùy ý (đổi nhanh phím `1`–`4`):**
  - **Vũ khí:** 🛡️ Xe tăng, 🔫 Súng máy hai nòng, 🎯 Pháo điện phòng không.
  - **Loại đạn:** 💥 Đạn đồng (kèm vỏ đạn văng), ⚡ Tia Laze, 🚀 Tên lửa tầm nhiệt (bay cong kéo khói), 🔮 Cầu Plasma.
- **Hiện nghĩa tiếng Việt + từ loại / cấu trúc + phát âm tiếng Anh tự động** ngay khi bắn hạ.
- **Sổ từ vựng 1.508 mục & Nhập bộ từ riêng** (CSV / JSON), lưu tiến độ riêng trên từng trình duyệt.
